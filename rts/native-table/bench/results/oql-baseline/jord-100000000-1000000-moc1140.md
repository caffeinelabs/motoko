# jcust / jord: 1,000,000 customers, 100,000,000 orders, moc 1.14.0

OQL: commit `bb5a23f` of `github.com/caffeinelabs/oql-prototype` ("fix: scope compiled predicates to one row stream (#107)", 2026-10-09), extracted with `git archive bb5a23f` into a scratch copy (README.md, "Setting up the OQL copies", gives the commands); dependencies core 2.6.0, jayson 0.1.1, bench 2.0.1 (`mops install`).
Replica: PocketIC 14.0.0 (`pocket-ic-server 14.0.0`, DFINITY's local test replica of the Internet Computer, the binary mops installs for OQL's `[toolchain]` pin), on an Apple M3 (macOS, 16 KiB host pages); dfx, DFINITY's SDK command-line tool, which runs a local replica of its own, was not used.
Compiler: `mops toolchain bin moc` of the copy: moc 1.14.0 (OQL's `[toolchain]` pin) and, in a second copy whose `mops.toml` pins moc 1.16.1, moc 1.16.1.


Rows: jcust row k = (region = k mod 100,000, tier = k mod 3); jord row k = (customerId = k mod 1,000,000, amount = k mod 1,000, status = floor(k / 1,000,000) mod 2, day = floor(k / 100,000)). Canister `bench/scale/oqlbars.mo`, copied from `src/oqlbars.mo` and built as `bench/scale/oqlbars.wasm` (README.md, "Setting up the OQL copies"; not `src/oqlbars-deadkeys.mo`, whose extra table `dkt` was added after this run had installed its canister): OQL's `bench/scale/main.mo` tables `jcust` and `jord`, the edge jord.customerId -> jcust, served through `Expose`. Both tables bulk-loaded through OQL's shipped producer (`uploadRows`, in flight 1); region `#hash` indexes uploaded through `putIndexSegment` (32,000,000 rows per segment) on jcust.region, jord.customerId and jord.status. The twelve queries are OQL JSON sent to `measure` as real query calls (the counter around `Executor.runWith`).

Load: jord 3118 s on this host. Indexes: jcust.region 14,691,520 B (14.692 B/row); jord.customerId 1,017,326,848 B (10.173 B/row); jord.status 800,000,672 B (8.000 B/row)

# M0196

This warning means that you supplied the `system` capability to a function that does not require it,
for example:

```motoko
import Prim "mo:prim";

actor {
  public func f() : async Blob {
    Prim.callerInfoSigner<system>() // `callerInfoSigner` does not take `system`
  };
};
```

The `system` argument is redundant and can be deleted: `Prim.callerInfoSigner()`.
Any remaining type arguments, as in `f<system, Nat>(...)`, are kept and checked as usual.

# M0279

This error means that the program uses `actor*`, the experimental local actor admitted by
`--experimental-local-actors`, and was compiled rather than only type checked.

`--experimental-local-actors` admits the `actor*` grammar and applies its typing rules, so
`moc --check` accepts a well-typed program that uses `actor*`. There is no lowering for
`actor*` yet, so compiling such a program fails, even when it is well typed.

Erroneous code example:

```motoko
// moc --experimental-local-actors -c counter.mo
actor* class Counter(initial : Nat) {
  var n = initial;
  public func add(delta : Nat) : async* Nat { n += delta; n };
};
```

To fix, use `actor*` only in programs that you type check with `moc --check`, or replace it
with an `actor` or an object.

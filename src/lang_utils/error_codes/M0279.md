# Invalid compute plugin call or declaration

A compute plugin is missing, or a call does not satisfy its argument contract.
Load the plugin with `moc --plugin <package-directory>` before compiling.

Type-specialized intrinsics infer their argument types at each call. For
example, `Prim.to_candid_canonical(value)` requires a shared type, as does
`to_candid`. It cannot encode a local function or mutable array. Annotate a value
when a particular input type is required.

Some intrinsics declare explicit type parameters. For example,
`Prim.from_json<User>(text)` specializes decoding to the concrete `User` type and
returns a typed result. Supply exactly the declared number of type arguments;
they cannot contain abstract parameters whose runtime representation is unknown.
Compute intrinsics do not accept a `system` capability. The plugin can also
reject types that its format or implementation does not support.

All plugin bindings retain their intrinsic identity through inferred aliases,
including fixed-input functions such as `Prim.sha256`. They cannot be annotated
as ordinary Motoko functions. Wrap a specialization in an ordinary Motoko
function with an explicit result type when a callback is needed:

```motoko
func hash(bytes : Blob) : Blob = Prim.sha256(bytes);
```

# M0279

This error means that a type definition or a class uses a type that a type pattern field binds later in the same block.

Type definitions and classes are checked before the `let` declarations of their block.
At that point, the type that `let { type T } = m` takes from `m` is not known yet, so the definition cannot refer to it:

```motoko
func f(m : module { type T = Nat }) {
  type U = T; // T is bound below
  let { type T } = m;
};
```

Move the `let` that binds the type above the definition that uses it:

```motoko
func f(m : module { type T = Nat }) {
  let { type T } = m;
  type U = T;
};
```

Other uses of the type, such as value annotations and function signatures, may still appear before the `let`.

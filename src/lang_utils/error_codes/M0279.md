# M0279

This error means that a native table cannot have the key type or the row type it is given.

A native table with key type `K` and row type `R` accepts:

- as `K`, one of `Nat`, `Int`, `Nat8` to `Nat64`, `Int8` to `Int64`, `Float`, `Bool`, `Char`, `Text`, `Blob` or `Principal`;
- as `R`, one of these types, or a record of immutable fields where each field has one of these types or an option of one.

Both types must be known where the table is made: neither may depend on a type parameter.

```motoko
import NativeTable "mo:native-table/NativeTable";

let a = NativeTable.empty<Nat, { name : Text; tags : [Text] }>(); // an array field
let b = NativeTable.empty<Nat, { name : Text; var visits : Nat }>(); // a mutable field
let c = NativeTable.empty<?Nat, { name : Text }>(); // an optional key

func make<R>() : NativeTable.Builder<Nat, R> = NativeTable.empty<Nat, R>() // a generic row type
```

A generic function that makes a table takes the table's codec as an implicit argument, so that its callers, which know the types, supply it:

```motoko
import Prim "mo:⛔";
import NativeTable "mo:native-table/NativeTable";

func make<R>(codec : (implicit : Prim.NtCodec<(Nat, R)>)) : NativeTable.Builder<Nat, R> =
  NativeTable.empty<Nat, R>();

let users = make<{ name : Text; city : Text }>().build()
```

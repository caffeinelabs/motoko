# M0280

This error means that an `actor*` (behind `--experimental-local-actors`) breaks one of the
rules for local actors.

A public field of an `actor*` is a local method. It is either an `async*` computation,
`public func m() : async* T`, or a synchronous method, `public func m() : T`. A local method is
monomorphic, and its parameters and result are immutable data (no `var` fields, mutable
arrays or local functions), actor or `actor*` references, or shared functions.

The `async` and `query` methods of a `public actor* class` declared directly in an actor are
exported through that actor, so an exported class name must be unique there. An internal
`actor*` cannot have `async` or `query` methods.

Erroneous code examples:

```motoko
// moc --experimental-local-actors --check counter.mo
actor* class Counter() {
  public query func peek() : async Nat { 0 };          // not a local method
  public func id<T>(x : T) : async* T { x };           // generic
  public func fill(xs : [var Nat]) : async* () { };    // mutable parameter
};
```

To fix, write the method as an `async*` computation or a synchronous method over immutable
values, or make the class a `public actor* class` of the actor that exports it.

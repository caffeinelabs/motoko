# M0270

This error means that a block of statements appeared in a position where
braces `{ ... }` enclose a record literal, for example on the right-hand side
of a `let`, as a function argument, or on the right of the `??` operator.

To evaluate a block of statements in such a position, use a `do` block:

```motoko
let x = do {          // not: let x = { ... }
  let y = f();
  y + 1
};

let n = opt ?? do {   // not: opt ?? { ... }
  Debug.print("default");
  0
};
```

If you meant to write a record literal, note that its fields are written
`name = expression` (or shorthand `name`), separated by `;`:

```motoko
let p = { x = 0; y = 0 };
```

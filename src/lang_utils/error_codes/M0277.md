# M0277

This error means that the body of a function spells out the `async` that its return type already implies.

The body of a function returning `async T` is implicitly asynchronous, whether it is written as a block or as `= <exp>`:

```motoko
func fetch() : async Nat = async { 42 }; // the body would be `async { async { 42 } }`
```

Write the body without `async`:

```motoko
func fetch() : async Nat { 42 };
func fetch2() : async Nat = 42; // the same
```

The same holds for `async*`, and for a one-way `shared` function, returning `()`, whose body is implicitly `ignore async`:

```motoko
public func notify() : () = ignore (async { log("hi") }); // a second message
public func notify() : () { log("hi") };
```

A parenthetical on the body, as in `= (with cycles = 1_000) async { ... }`, belongs where the function is called instead: `(with cycles = 1_000) fetch()`.

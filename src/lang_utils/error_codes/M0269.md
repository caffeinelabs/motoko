# M0269

This error means that a record literal `{ ... }` appeared where braces mean
something else: in statement position — a function body, a `case` arm, an
`if` branch, or the top level — `{ ... }` is a block of declarations, so a
field definition like `x = 0` is not valid inside it.

To produce a record from such a position, write the record literal as the
result expression of the block, where braces mean a record again:

```motoko
func origin() : Point {
  { x = 0; y = 0 }
};

func step(p : Point, d : Dir) : Point {
  switch d {
    case #right { { p with x = p.x + 1 } }
    case #left { { p with x = p.x - 1 } }
  }
};
```

If you meant something else:

* to declare a variable, use `let x = 0` or `var x = 0`;
* to assign to a mutable variable, use `x := 0`.

The same error is reported for a record literal written directly as a
`switch`/`if`/`while` head, where the `{` already belongs to the construct's
body; parenthesize the record in that (rare) case.

# M0269

This error means that a record literal `{ ... }` appeared in a position where
braces have another meaning:

* in statement position (a block body, the top level of a program, or an actor,
  module, or object body), `{ ... }` is a block of declarations, so
  `x = 0` inside it is not a record field;
* directly after `if`, `while`, or `switch`, the `{` already belongs to the
  construct's body, so it cannot start the condition or scrutinee.

To write a record in such a position, wrap it in parentheses:

```motoko
func origin() : { x : Nat; y : Nat } {
  ({ x = 0; y = 0 })  // not { x = 0; y = 0 }
};

switch ({ x = 0 }) {  // not: switch { x = 0 } { ... }
  case _ {}
}
```

If you meant something else:

* to declare a variable, use `let x = 0` or `var x = 0`;
* to assign to a mutable variable, use `x := 0`;
* to run a block of statements where an expression is expected, use
  `do { ... }`.

# M0275

This error means that the branches of an `if` (or the body of a `while` or
`for`) were written as bare expressions while the condition or head is an
unparenthesized compound expression: a call, an indexing, a projection, or an
operator application.

When the head is written without parentheses, the branches or body must be
blocks:

```motoko
if f(x) { e1 } else { e2 };   // not: if f(x) e1 else e2
while n > 0 { n -= 1 };       // not: while n > 0 n -= 1
for x in xs.vals() { go(x) };
```

Alternatively, keep the branches bare and parenthesize the condition, in the
pre-existing style:

```motoko
if (f(x)) e1 else e2;
```

Whether a `(` or `[` directly after a bare identifier still belongs to the
condition is decided by whitespace: `if c[i] ...` indexes `c`, so its branches
must be blocks, while `if c [i] else []` is the condition `c` followed by the
bare branch `[i]`. A prefix-shaped operator after the condition always starts
the branch: `if (c) -1 else 1`, `if (c) ^mask else mask`, and
`if (c) #less else #greater` keep their meaning, while `if n - 1 > 0 { }` and
`if n-1 > 0 { }` are conditions.

The same error is reported when the body of a `switch` or `do` is not a block,
as in `switch (x) e` or `do e`: these constructs always take a block.

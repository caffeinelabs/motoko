# M0275

This error means that the branches of an `if` (or the body of a `while` or
`for`) were written as bare expressions while the condition or head is not
parenthesized.

An `if`/`while` has two shapes. With a parenthesized condition the branches may
be any expression, as they always could:

```motoko
if (c) e1 else e2;
while (n > 0) n -= 1;
```

Without the parentheses the condition may be any expression, and the branches
or body must be blocks:

```motoko
if c { e1 } else { e2 };
if f(x) { e1 } else { e2 };   // not: if f(x) e1 else e2
while n > 0 { n -= 1 };       // not: while n > 0 n -= 1
for x in xs.vals() { go(x) };
```

The opening parenthesis decides the shape: a condition that starts with `(`
ends at the matching `)`. So `if (c) -1 else 1` keeps its meaning, while a
compound condition that would start with `(` needs to be parenthesized as a
whole, `if ((a + b) * c > 0) { }`, or written without the leading group.

Note that `if c[i] else []` is the first shape: `c[i]` is an index into `c`,
so its branches must be blocks. To test `c` and produce the array `[i]`, write
`if (c) [i] else []`.

The same error is reported when the body of a `switch` or `do` is not a block,
as in `switch (x) e` or `do e`: these constructs always take a block.

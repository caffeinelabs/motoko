# M0272

This error means that the branches of an `if` (or the body of a `while` or
`for`) were written as bare expressions while the condition or head is an
unparenthesized expression.

When the head is written without parentheses, the branches or body must be
blocks:

```motoko
if f(x) { e1 } else { e2 };   // not: if f(x) e1 else e2
while n > 0 { n -= 1 };       // not: while n > 0 n -= 1
for x in xs.vals() { go(x) };
```

Alternatively, keep the branches bare and parenthesize the condition, in the
pre-existing style:

```motoko
if (f(x)) e1 else e2;
```

The same error is reported when the body of a `switch` or `do` is not a block,
as in `switch (x) e` or `do e`: these constructs always take a block.

# M0271

This error means that a reserved keyword of the Motoko language (such as
`query`, `stable`, `implicit`, or `in`) was used where an identifier is
expected, for example as a variable, field, or function name.

Keywords cannot be used as identifiers. Choose a different name, for example
by appending an underscore:

```motoko
let query_ = 5;      // not: let query = 5
```

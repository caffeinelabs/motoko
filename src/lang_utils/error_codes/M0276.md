# M0276

This error means that a comparison always has the same result, because it is performed at a type that has exactly one value, such as `Any`, `{}`, `()` or `Null`.
A comparison at such a type cannot observe any difference between its operands.

The error is reported only when that type was not written for both operands: their types differ, and their common supertype is the single-valued type, a type parameter is compared at its bound, or a literal is compared with a value of type `Any`, as in `x == 10`.

This is almost always a mistake, such as comparing the wrong variables, or two records that share no field:

```motoko
let n : Nat = 1;
let t : Text = "1";
n == t; // compared at `Any`

let user = { id = 1; name = "Ann" };
let order = { userId = 1; total = 10 };
user == order; // compared at `{}`

func eq<A, B>(a : A, b : B) : Bool = a == b; // compared at `Any`
```

Compare the fields you mean explicitly, or convert the operands to a common type first:

```motoko
user.id == order.userId;
Nat.toText(n) == t;
```

For generic code, take an equality function as a parameter instead:

```motoko
func eq<A>(a : A, b : A, equal : (A, A) -> Bool) : Bool = equal(a, b);
```

When both operands already have the single-valued type, the comparison is accepted, because the type was declared that way on purpose:

```motoko
type Admin = { status : { #active } };
func isActive(a : Admin) : Bool = a.status == #active; // always `true`, but accepted
```

If the constant result is really intended in the other cases, `-W M0276` reports this as a warning instead of an error.

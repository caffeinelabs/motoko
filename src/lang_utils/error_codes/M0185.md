# M0185

This warning means that an imported Candid file (`.did`) describes a service
constructor rather than a service: its `service` takes initialization
arguments, which a canister receives once, when it is installed.

Example of such a Candid file, as generated for an actor class:

```candid
service : (owner : principal) -> {
  greet : (text) -> (text);
}
```

Importing it, e.g. with `import Backend "canister:backend"`, gives you the
canister as the service it creates, as if the file read

```candid
service : {
  greet : (text) -> (text);
}
```

The initialization arguments are ignored. They do not matter for calling the
methods of an installed canister, so if that is all you do, the warning is
harmless.

If you wrote the Candid file by hand, you can avoid the warning by removing the
initialization arguments, as in the second example above. If the file is
generated for a canister, e.g. for a `canister:` import, leave it as it is;
the warning only tells you that the arguments are not part of the import.
